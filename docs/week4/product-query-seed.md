# 상품 조회 측정용 데이터 (seed)

4주차 조회 · 인덱스 · 캐시 비교에 쓰는 데이터다. 제품 데이터가 아니며, 같은 규칙으로 언제든 같은 데이터를 다시 만든다.

- seed: `apps/commerce-api/src/test/resources/seed/week4-product-seed.sql`
- 실행 · 검증: `RUN_EXPERIMENT=true ./gradlew :apps:commerce-api:test --tests '*ProductQueryExperiment'` (평소 `check` 에서는 건너뜀)
- 네이티브 MySQL: 앱을 띄워 스키마가 만들어진 뒤(`ddl-auto: create`) `mysql -u application -p loopers < week4-product-seed.sql`

## 1. 넣는 방법

| 방안 | 판단 |
|---|---|
| SQL 파일 (재귀 CTE) | **채택.** 1만 건 · 10만 건을 한 번에 넣고, Testcontainers와 네이티브 MySQL에 같은 파일을 쓴다. 저장소에 재현 자료로 남는다 |
| 도메인 서비스 · API로 생성 | 불변식 검증은 거치지만 느리고, 생성 시각이 거의 같아져 `latest` 정렬이 식별자 순서와 구분되지 않는다 |

- 스키마는 `ddl-auto: create` 로 매번 다시 만들어지므로 seed는 컨텍스트가 뜬 **뒤에** 넣는다.
- SQL은 도메인 검증을 거치지 않는다. 엔티티와 어긋나지 않았는지는 아래 검증값을 실험 시작 전에 assertion으로 확인해 막는다.

## 2. 규칙

i = 상품 순번이자 식별자 (1..10,000)

| 대상 | 규칙 | 의도 |
|---|---|---|
| users | 1,000명 | 좋아요 관계의 `user_id` 가 실제 행을 가리키게 한다 |
| brand | 100개, 모두 살아 있음 | |
| 상품의 브랜드 | `(i % 100) + 1` | 과제 예시 분포와 같다 |
| 가격 | `((i * 37) % 100000) + 100` | 과제 예시 분포와 같다. 37과 100000이 서로소라 **이 범위에는 가격 동점이 없다** |
| 생성 시각 | 기준 + `(i * 7919) % 10000` 초 | 식별자 순서와 다른 순열(중복 없음). `latest` 정렬 비용이 PK 순서와 섞이지 않게 한다 |
| 삭제 | `i % 17 = 0` → 588개 | 17과 100이 서로소라 모든 브랜드에 퍼진다. `deleted_at IS NULL` 조건의 비용이 측정에 들어간다 |
| 재고 0 | `i % 13 = 0` | `soldOut` 참 · 거짓이 섞인다 |
| 좋아요 수 L(i) | `i % 97 = 0` → 250 (인기), `i % 7 = 0` → 0, 나머지 `((i * 31) % 97) % 17 + 1` (1..17) | 0개 · 동점 · 인기 상품이 모든 브랜드에 섞인다 |
| 좋아요 사용자 | 상품 i 의 j 번째(0 ≤ j < L(i)) = `((i * 7 + j) % 1000) + 1` | 같은 상품 안에서 사용자가 겹치지 않아 유니크 키를 지킨다 |

- 삭제된 상품의 좋아요 관계도 남긴다. 상품을 삭제해도 관계는 남는다는 기존 규칙(2주차 설계 6.3)과 같은 상태다.
- 좋아요 총량은 10만 건 규모를 목표로 했고, 규칙을 단순하게 두기 위해 정확히 10만으로 맞추지 않았다.
- 가격순 동점 확인은 이 seed가 아니라 별도의 작은 자료로 한다.

## 3. 검증값

| 항목 | 값 |
|---|---|
| 사용자 | 1,000 |
| 전체 상품 / 가격 합계 | 10,000 / 472,685,000 |
| 살아 있는 상품 / 가격 합계 | 9,412 / 445,004,786 |
| 브랜드 7 전체 / 가격 합계 | 100 / 4,647,200 |
| 브랜드 7 살아 있는 상품 / 가격 합계 | 94 / 4,435,168 |
| 좋아요 전체 / 살아 있는 상품의 좋아요 | 100,163 / 94,276 |
| 없는 사용자를 가리키는 좋아요 | 0 |

측정 대상인 브랜드 7의 살아 있는 상품 94개에는 좋아요 0개 12개, 인기 상품 1개, 서로 다른 좋아요 수 19종(동점 다수), 품절 8개가 있다.
